# 02 配置详解

`config/kafka.php` 全部字段 + `.env` 环境变量 + `config/queue.php` 关联。

---

## 文件结构

```
config/
├── app.php           # 业务方一般不改
├── queue.php         # 这里要改 default connection
├── database.php      # KAFKA_FAILED_DB_CONNECTION 用
└── kafka.php         # 本包主配置（vendor:publish 生成）
```

`config/kafka.php` 顶层结构：

```php
return [
    'default' => env('KAFKA_CONNECTION', 'default'),

    'connections' => [
        'default' => [
            // 基础连接
            'brokers'   => env('KAFKA_BROKERS', 'localhost:9092'),
            'client_id' => env('KAFKA_CLIENT_ID', 'laravel-kafka'),
            'protocol'  => env('KAFKA_PROTOCOL', 'PLAINTEXT'),
            'sasl'      => [...],
            'ssl'       => [...],

            // topic
            'queue'     => env('KAFKA_DEFAULT_TOPIC', 'laravel-jobs'),
            'topics'    => [...],

            // 子配置
            'producer'  => [...],
            'consumer'  => [...],
            'failed'    => [...],
            'delay'     => [...],
            'replay'    => [...],
        ],
        // 可以加 'reports' / 'high-priority' 等更多 connection
    ],
];
```

## 字段速查表

### 基础连接

| 字段 | 环境变量 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `brokers` | `KAFKA_BROKERS` | `localhost:9092` | 引导 broker 列表，逗号分隔，如 `h1:9092,h2:9092,h3:9092` |
| `client_id` | `KAFKA_CLIENT_ID` | `laravel-kafka` | librdkafka `client.id`，用于 broker 端识别客户端 |
| `protocol` | `KAFKA_PROTOCOL` | `PLAINTEXT` | `PLAINTEXT` / `SSL` / `SASL_PLAINTEXT` / `SASL_SSL`（见 [14-安全连接](14-安全连接.md)） |

### SASL（可选）

```php
'sasl' => [
    'mechanism' => env('KAFKA_SASL_MECHANISM'),   // PLAIN / SCRAM-SHA-256 / SCRAM-SHA-512
    'username'  => env('KAFKA_SASL_USERNAME'),
    'password'  => env('KAFKA_SASL_PASSWORD'),
],
```

> 当 `protocol` 为 `SASL_PLAINTEXT` 或 `SASL_SSL` 时生效。

### SSL（可选）

```php
'ssl' => [
    'ca_location'   => env('KAFKA_SSL_CA'),         // CA 证书路径
    'cert_location' => env('KAFKA_SSL_CERT'),       // 客户端证书路径
    'key_location'  => env('KAFKA_SSL_KEY'),        // 客户端私钥路径
    'key_password'  => env('KAFKA_SSL_KEY_PASSWORD'), // 私钥密码（可选）
],
```

> 当 `protocol` 为 `SSL` 或 `SASL_SSL` 时生效。

### 默认 topic + 队列名映射

```php
'queue'  => env('KAFKA_DEFAULT_TOPIC', 'laravel-jobs'),
'topics' => [
    // 'emails'  => 'app.emails',
    // 'reports' => 'app.reports',
],
```

- `queue` —— Laravel 队列名当 topic 名（兼容最常用场景）
- `topics` —— 显式映射：Laravel 逻辑队列名 → 物理 topic 名

> 优先级：业务方 `Queue::push($job, '', 'queue', 'key')` 显式指定 > `topics` 映射 > `queue` 默认

### Producer 配置

| 字段 | 环境变量 | 默认 | librdkafka 原生 key |
| --- | --- | --- | --- |
| `compression` | `KAFKA_PRODUCER_COMPRESSION` | `snappy` | `compression.type` |
| `batch_size` | `KAFKA_PRODUCER_BATCH_SIZE` | `10000` | `batch.size`（字节） |
| `linger_ms` | `KAFKA_PRODUCER_LINGER_MS` | `5` | `linger.ms` |
| `request_timeout_ms` | `KAFKA_PRODUCER_REQUEST_TIMEOUT_MS` | `30000` | `request.timeout.ms` |
| `message_timeout_ms` | `KAFKA_PRODUCER_MESSAGE_TIMEOUT_MS` | `30000` | `message.timeout.ms` |
| `enable_idempotence` | `KAFKA_PRODUCER_IDEMPOTENCE` | `true` | `enable.idempotence` |
| `acks` | `KAFKA_PRODUCER_ACKS` | `all` | `acks` |

### Consumer 配置

| 字段 | 环境变量 | 默认 | librdkafka 原生 key |
| --- | --- | --- | --- |
| `group_id` | `KAFKA_GROUP_ID` | `laravel-default` | `group.id` |
| `auto_offset_reset` | `KAFKA_AUTO_OFFSET_RESET` | `error` | `auto.offset.reset` |
| `enable_auto_commit` | — | `false`（必 false） | `enable.auto.commit` |
| `max_poll_interval_ms` | `KAFKA_MAX_POLL_INTERVAL_MS` | `300000` | `max.poll.interval.ms` |
| `session_timeout_ms` | `KAFKA_SESSION_TIMEOUT_MS` | `45000` | `session.timeout.ms` |
| `heartbeat_interval_ms` | `KAFKA_HEARTBEAT_INTERVAL_MS` | `3000` | `heartbeat.interval.ms` |
| `fetch_min_bytes` | `KAFKA_FETCH_MIN_BYTES` | `1` | `fetch.min.bytes` |
| `fetch_max_bytes` | `KAFKA_FETCH_MAX_BYTES` | `52428800` | `fetch.max.bytes`（50MB） |
| `isolation_level` | `KAFKA_ISOLATION_LEVEL` | `read_committed` | `isolation.level` |

> `auto_offset_reset` 取值：
> - `earliest` —— 没消费过 / offset 失效时从 topic 头开始
> - `latest` —— 跳到 topic 尾部（仅消费新消息）
> - `error` —— 抛异常（生产推荐，避免静默跳过历史消息）

### 失败处理

```php
'failed' => [
    'driver'   => env('KAFKA_FAILED_DRIVER', 'hybrid'),   // database | dlq | hybrid

    // database / hybrid 模式：写到 Laravel failed_jobs 表
    'database' => [
        'table'      => env('KAFKA_FAILED_TABLE', 'failed_jobs'),
        'connection' => env('KAFKA_FAILED_DB_CONNECTION'), // null = 用默认 DB connection
    ],

    // dlq / hybrid 模式：写独立 topic
    'dlq' => [
        'topic'             => env('KAFKA_DLQ_TOPIC'),     // null = 自动 <default>.dlq
        'auto_topic_suffix' => env('KAFKA_DLQ_AUTO_SUFFIX', '.dlq'),
        'retention_ms'      => (int) env('KAFKA_DLQ_RETENTION_MS', 1209600000), // 14d
    ],

    // hybrid 模式策略
    'hybrid' => [
        'fatal_exceptions'        => [
            // \LaravelKafka\Exceptions\SerializationException::class,
            // \Illuminate\Validation\ValidationException::class,
        ],
        'max_attempts'           => (int) env('KAFKA_MAX_ATTEMPTS', 3),
        'trace_truncate_bytes'   => (int) env('KAFKA_TRACE_TRUNCATE', 32768),
        'message_truncate_bytes' => (int) env('KAFKA_MESSAGE_TRUNCATE', 4096),
    ],
],
```

> 详细失败处理流程见 [05-失败处理](05-失败处理.md)。

### 延迟消息

```php
'delay' => [
    'strategy' => env('KAFKA_DELAY_STRATEGY', 'time_wheel'),  // 当前只支持 time_wheel
    'tiers'    => [5, 30, 60, 300, 1800, 3600, 86400],         // 7 层时间轮（秒）
],
```

> 详见 [06-延迟消息](06-延迟消息.md)。

### 回溯

```php
'replay' => [
    'preserve_partition' => true,   // 回放时是否保持原 partition
],
```

> 详见 [08-回溯Replay](08-回溯Replay.md)。

## 多个 connection

```php
'connections' => [
    'default' => [
        'brokers' => 'kafka-main:9092',
        'queue'   => 'laravel-jobs',
        // ...
    ],
    'reports' => [
        'brokers' => 'kafka-reports:9092',
        'client_id' => 'laravel-kafka-reports',
        'queue'   => 'app-reports',
        // ... 独立完整配置
    ],
    'audit' => [
        'brokers' => 'kafka-audit:9092',
        'protocol' => 'SASL_SSL',
        'sasl' => ['mechanism' => 'SCRAM-SHA-512', 'username' => '...', 'password' => '...'],
        'ssl'  => ['ca_location' => '/etc/ssl/ca.pem', ...],
        'queue' => 'audit-events',
        // ...
    ],
],
```

使用：

```php
// 默认 connection
Queue::push(new MyJob());

// 显式指定
Queue::connection('reports')->push(new ReportJob());
Kafka::connection('reports')->config()->brokers();  // 'kafka-reports:9092'
```

详见 [10-多Connection](10-多Connection.md)。

## `config/queue.php` 关联

> **v0.5.2 修正**：本包通过 `Queue::extend('kafka', ...)` 在 `boot()` 注册 `kafka` **驱动 connector**
> （`LaravelKafkaServiceProvider`），但**没有**自动注册 `queue.connections.kafka` 连接条目。
> Laravel 在 `QUEUE_CONNECTION=kafka` 时会查 `queue.connections.kafka`——**不存在会报
> "Queue connection [kafka] not configured"**。需要在 `config/queue.php` 加连接条目：

```php
// config/queue.php
'connections' => [
    'kafka' => [
        'driver' => 'kafka',   // 触发本包 Queue::extend 注册的 connector
        // 本包配置从 config/kafka.php 读（brokers/topic/consumer 等）
    ],
    // ... 其他连接
],
```

然后切换默认 queue connection：

```php
'default' => env('QUEUE_CONNECTION', 'kafka'),
```

或者在 `.env`：

```dotenv
QUEUE_CONNECTION=kafka
```

## 完整 `.env` 模板

```dotenv
# 队列默认驱动
QUEUE_CONNECTION=kafka

# Kafka 基础
KAFKA_BROKERS=localhost:9092
KAFKA_DEFAULT_TOPIC=laravel-jobs
KAFKA_GROUP_ID=laravel-default
KAFKA_CLIENT_ID=laravel-kafka

# 协议（PLAINTEXT / SSL / SASL_PLAINTEXT / SASL_SSL）
KAFKA_PROTOCOL=PLAINTEXT

# Producer
KAFKA_PRODUCER_COMPRESSION=snappy
KAFKA_PRODUCER_BATCH_SIZE=10000
KAFKA_PRODUCER_LINGER_MS=5
KAFKA_PRODUCER_IDEMPOTENCE=true
KAFKA_PRODUCER_ACKS=all

# Consumer
KAFKA_AUTO_OFFSET_RESET=error
KAFKA_MAX_POLL_INTERVAL_MS=300000
KAFKA_SESSION_TIMEOUT_MS=45000

# 失败处理
KAFKA_FAILED_DRIVER=hybrid
KAFKA_FAILED_TABLE=failed_jobs
KAFKA_FAILED_DB_CONNECTION=
KAFKA_DLQ_TOPIC=
KAFKA_DLQ_AUTO_SUFFIX=.dlq
KAFKA_DLQ_RETENTION_MS=1209600000
KAFKA_MAX_ATTEMPTS=3
KAFKA_TRACE_TRUNCATE=32768
KAFKA_MESSAGE_TRUNCATE=4096

# 延迟
KAFKA_DELAY_STRATEGY=time_wheel

# 默认序列化器（v0.5.1：php / json）
KAFKA_SERIALIZER=php
```
