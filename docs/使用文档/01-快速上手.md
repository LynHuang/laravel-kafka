# 01 快速上手

5 分钟跑通：从安装到第一个消息入队 + 消费完成。

---

## 前置条件

| 组件 | 最低版本 | 说明 |
| --- | --- | --- |
| PHP | 7.4 | 推荐 8.1+ |
| ext-rdkafka | * | 任意（推荐 librdkafka ≥ 1.5） |
| Laravel | 8.x | 9 / 10 / 11 均可 |
| Kafka broker | 0.11+ | KRaft 单节点 / 集群均可 |

> 本地开发推荐用 [Docker Hub confluentinc/cp-kafka](https://hub.docker.com/r/confluentinc/cp-kafka) 起一个 KRaft 单节点。

---

## 1. 安装 ext-rdkafka

### macOS

```bash
brew install librdkafka
pecl install rdkafka
```

### Ubuntu / Debian

```bash
sudo apt-get update
sudo apt-get install -y librdkafka-dev
pecl install rdkafka
```

### 验证

```bash
php -m | grep rdkafka
```

应输出 `rdkafka`。如果没装，Composer 安装时会报 `ext-rdkafka 缺失`。

---

## 2. Composer 安装

```bash
composer require lyn-huang/laravel-kafka
```

包安装后**自动**注册 `LaravelKafkaServiceProvider` 和 `Kafka` Facade（`composer.json` 的 `extra.laravel` 段声明），无需手动改 `config/app.php`。

---

## 3. 发布配置文件

```bash
php artisan vendor:publish --tag=kafka-config
```

会在 `config/kafka.php` 生成配置文件（包含默认 connection + 全部子项）。

---

## 4. 配置 `.env`

```dotenv
# ===== 队列默认驱动 =====
QUEUE_CONNECTION=kafka

# ===== Kafka broker =====
KAFKA_BROKERS=localhost:9092
KAFKA_DEFAULT_TOPIC=laravel-jobs
KAFKA_GROUP_ID=laravel-default

# ===== 失败处理（database / dlq / hybrid） =====
KAFKA_FAILED_DRIVER=hybrid
```

> 完整环境变量清单见 [02-配置详解](02-配置详解.md)。

---

## 5. 启动 Kafka broker（本地）

```bash
docker run -d --name kafka \
  -p 9092:9092 \
  -e KAFKA_PROCESS_ROLES=broker,controller \
  -e KAFKA_CONTROLLER_LISTENER_NAMES=CONTROLLER \
  -e KAFKA_NODE_ID=1 \
  -e KAFKA_LISTENER_SECURITY_PROTOCOL_MAP=CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT \
  -e KAFKA_LISTENERS=PLAINTEXT://0.0.0.0:9092,CONTROLLER://0.0.0.0:9093 \
  -e KAFKA_ADVERTISED_LISTENERS=PLAINTEXT://localhost:9092 \
  -e KAFKA_CONTROLLER_QUORUM_VOTERS=1@localhost:9093 \
  -e KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR=1 \
  -e KAFKA_TRANSACTION_STATE_LOG_REPLICATION_FACTOR=1 \
  -e KAFKA_TRANSACTION_STATE_LOG_MIN_ISR=1 \
  confluentinc/cp-kafka:7.5.0
```

## 6. 第一个 push

业务方代码：

```php
<?php

namespace App\Jobs;

use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;

class SendOrderEmail implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(public int $orderId) {}

    public function handle(): void
    {
        // 实际发邮件逻辑
        \Mail::to("user-{$this->orderId}@example.com")->send(new \App\Mail\OrderShipped($this->orderId));
    }
}
```

dispatch：

```php
use App\Jobs\SendOrderEmail;

// 在 controller / service / 命令行
SendOrderEmail::dispatch(12345);
```

这条消息会立即同步写入 Kafka topic `laravel-jobs`，无 broker 报错即视为成功。

---

## 7. 启动 worker

```bash
php artisan kafka:work --queue=laravel-jobs
```

输出示例：

```
[kafka:work] starting on topics=[laravel-jobs] group=laravel-default
ACK offset=0 topic=laravel-jobs
ACK offset=1 topic=laravel-jobs
...
```

按 `Ctrl+C` 触发 SIGINT，worker 处理完当前消息后优雅退出。

## 常见问题

**Q：启动 worker 报 "Connection refused"？**
A：检查 `KAFKA_BROKERS` 环境变量（默认 `localhost:9092`），以及 Kafka broker 是否真的在该端口监听。可以用 `kafkacat -b localhost:9092 -L` 或 `kcat -L -b localhost:9092` 验证。

**Q：push 时报 "Kafka produce timeout after 5000 ms"？**
A：librdkafka 5 秒内没收到 delivery report。常见原因：
1. broker 地址错（检查 `KAFKA_BROKERS`）
2. broker 慢 / 磁盘满
3. `acks=all` 但 `min.insync.replicas` 大于实际副本数

**Q：worker 启动了但收不到消息？**
A：检查
1. `Kafka::connection()->push()` 是否成功返回（看日志）
2. `KAFKA_GROUP_ID` 是否一致（同 group 内 partition 互斥，不同 group 各自从头消费）
3. `KAFKA_AUTO_OFFSET_RESET` 配置（`earliest` = 从头消费，`latest` = 跳过历史）
