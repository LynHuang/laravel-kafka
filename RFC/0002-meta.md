# RFC 0002 - 项目元信息

## 状态

✅ Accepted

## 日期

2026-08-20

## 摘要

确定 `laravel-kafka` v0.1 的六项项目级决策：

| 项 | 决议 |
| --- | --- |
| Horizon 适配 | **v0.1 ~ v0.3 不做**，v0.4 重新评估 |
| Laravel Octane 兼容 | **v0.1 ~ v0.3 不做**，v0.4 重新评估 |
| 失败任务查询 UI | **v0.1 不做** |
| License | **MIT** |
| CI 矩阵 | **PHP 7.4 / 8.1 / 8.3** |
| GitHub 仓库可见性 | **先私有** |

## 详细方案

### Horizon / Octane / UI 三不沾

- 这三项都涉及"在 Laravel 内部生态里深度集成"
- v0.1 资源聚焦核心队列 + 三模式失败处理，先把"作为 Queue 驱动"这条主路径做稳
- v0.2 扩展 Kafka 特色功能（DLQ 高级、延迟、Replay）
- v0.3 事务 + 多 Consumer Group
- v0.4 重新评估这三项的"做不做 + 怎么做"

### License: MIT

- 与 Laravel 生态一致
- `composer.json` 必填 `"license": "MIT"`
- 仓库根放 `LICENSE` 文件（已实现）

### CI 矩阵

- 仅测 **PHP 7.4 / 8.1 / 8.3** 三个代表版本
- 与 Laravel 组合后产生 6 个有效组合（7.4 + Laravel 8；8.1 + L9/10/11；8.3 + L10/11）
- PHP 8.0 / 8.2 不测（与相邻版本行为差异小，省 CI 成本）
- 完整配置见 `.github/workflows/tests.yml`

### GitHub 仓库先私有

- **影响 1：不能上 Packagist 公共仓库**
  - 使用方需在项目 `composer.json` 配 `repositories.vcs` + GitHub PAT
- **影响 2：CI 拉取**
  - GitHub Actions 同 owner 私有仓库可免 token
- **影响 3：贡献者**
  - 私有期只接受显式邀请

## 兼容性影响

- **MIT License**：允许任何商业 / 个人项目使用、修改、分发；保留版权声明
- **私有仓库**：外部用户不能直接 `composer require`，需走 GitHub 仓库源
- **CI 矩阵缩小**：PHP 8.0/8.2 用户可能遇到本包能跑但 CI 没覆盖的 corner case

## 替代方案

### License

- ❌ Apache-2.0：与 Laravel MIT 不一致，企业用户更习惯 MIT
- ✅ MIT：与 Laravel / Symfony / Doctrine 等主流 PHP 包一致

### CI 矩阵

- ❌ PHP 5 组合：早已 EOL
- ❌ PHP 8.0 / 8.2 加进来：CI 时间翻倍
- ✅ 7.4 / 8.1 / 8.3 三个代表版本：覆盖关键行为路径

### 仓库可见性

- ❌ 直接公开：v0.1 还没稳定，公开后会被搜索引擎抓到烂摊子
- ✅ 先私有：迭代 3-4 个小版本稳定后再转公开

## 决策

全部 ✅ Accepted，详见 §11.1 / §14。
